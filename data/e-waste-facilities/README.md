# Authorized E-Waste Facilities in India (All 36 States & UTs)

## Overview

A nationwide, fully geolocated, and contact-enriched dataset of authorized electronic waste facilities across **all 36 States and Union Territories** in India, compliant with the **E-Waste (Management) Rules, 2022**.

## Summary Metrics

| Metric | Value |
|--------|-------|
| **Total Authorized Facilities** | **421** |
| **States & UTs Covered** | **36 / 36 (100% Coverage)** |
| **Total Processing Capacity** | **1,664,988 MTA** |
| **Facility Types** | Recyclers, Dismantlers, Refurbishers, Authorized Collection Centers |
| **Authorization Flags** | `is_authorized` (true), `authorization_status` ("Authorized"), `authorization_by` (SPCB/PCC) |
| **Geolocation** | Exact Latitude, Longitude, Direct Google Maps URL, Pin Coordinate Link |
| **Contact Data** | Phone, Toll-Free, Email, Website, Contact Person / EHS Officer |
