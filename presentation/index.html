The Problem

India's E-Waste Challenge

  • Scale: India generates ~3.2 million tonnes of e-waste annually (CPCB 2023)
  • Processing Gap: Only 22% is collected and processed through authorized channels
  • Informal Sector Issues:
    • Environmental contamination (lead, mercury, cadmium)
    • Health hazards for workers
    • Loss of valuable resources (gold, silver, copper)
    • Economic loss from improper recycling

Need for:

  • Verification system
  • Authorized facility access
  • Incentive mechanism

Our Solution

e locate Platform

A comprehensive platform that combines:

  • 🤖 AI-Powered Device Verification: Identify e-waste items using smartphone camera
  • 🗺️ National Facility Directory: 421+ authorized e-waste facilities across India
  • 💰 Reward System: Earn credits for responsible disposal
  • 📋 Compliance Tools: EPR certificates, pickup scheduling

Technical Architecture

Built with Modern Technologies

Frontend (Client-Side):

  • HTML5/CSS3/JavaScript (Vanilla JS)
  • Leaflet.js for interactive maps
  • Responsive design (dark/light themes)
  • localStorage for persistence
  • MediaDevices API for camera access

Backend (Server-Side):

  • Node.js/Express.js REST API
  • AI verification endpoint (NVIDIA/OpenAI integration)
  • CORS-enabled for security
  • 16MB payload handling for image uploads
  • Environment-based configuration

Data Layer:

  • JSON facility datasets (421+ records)
  • Device composition database
  • User wallet & transaction logs
  • Audit trails for compliance

AI Verification Process

From Image to Insights

  1. Image Capture: Live camera or upload
  2. Preprocessing: Image optimization for AI
  3. AI Analysis: NVIDIA Llama 3.2 Vision API
  4. Result Parsing: Structured JSON output
  5. User Display:
    • E-waste verdict badge
    • 4-point metadata grid (Item, Category, Subcategory, Condition)
    • Confidence gauge (0-100%)
    • Material breakdown & value estimation
    • Environmental impact metrics

Implementation Demo Flow

User Journey Walkthrough

  1. User opens app → Sees KPI dashboard (421 facilities, 1.66M MTA)
  2. Clicks "Verify Device" → Camera interface appears
  3. Captures/upload image → AI processes e-waste item (e.g., laptop)
  4. AI results show →
    • "E-Waste Item Identified" banner
    • Device details (laptop, electronics, used)
    • Confidence: 92%
    • Material breakdown (copper, gold, plastic)
    • Value: ₹850
    • CO₂ offset: 12kg
  5. Clicks "Find Facilities for this Item" → Map filters to suitable recyclers
  6. Selects facility → Views details, contacts, schedules pickup
  7. Completes verification → Earns credits → Downloads EPR certificate
