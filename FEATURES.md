## 1. AI Vision & Identification Engine

| Feature | Description | Scope |
| :--- | :--- | :--- |
| **Live Camera Viewfinder** | Real-time video stream via HTML5 `MediaDevices.getUserMedia` with video playback and active status indicators. | Core |
| **Camera Facing Mode Switcher** | 1-click floating button to toggle between front (user) and rear (environment) cameras on mobile devices. | Micro |
| **Canvas Frame Grabber** | Captures high-resolution frames from the live video feed into an in-memory HTML5 Canvas and converts to JPEG Data URLs. | Core |
| **Drag & Drop Upload Zone** | Interactive dropzone supporting drag-and-drop and file dialog selection for JPG, PNG, and WebP images. | Core |
| **NVIDIA Llama 3.2 Vision Relay** | Express API backend relay connecting to `meta/llama-3.2-11b-vision-instruct` with multimodal base64 image parsing. | Core |
| **Strict JSON Output Enforcement** | System prompting with guaranteed deterministic JSON schema output. | Core |
| **Resilient JSON Recovery Parser** | Cleanses and extracts JSON objects from API responses even if wrapped in markdown code blocks or surrounding text. | Backend |
| **E-Waste Verdict Banner** | Instant color-coded classification badge (`E-Waste Item Identified` vs `Not Classified as E-Waste`). | UI |
| **4-Point Metadata Grid** | Structured breakdown displaying: **Item Name**, **Category**, **Subcategory**, and **Condition**. | UI |
| **Condition-Specific Highlighting** | Color-coded condition pill tags (Green for *New/Refurbished*, Blue for *Used*, Red for *Damaged/Broken*). | Micro |
| **Animated Confidence Gauge** | Dynamic 0–100% confidence level display with a smooth animated progress line. | Micro |
| **Visual Notes & Inspection Insights** | Natural language description generated by AI describing visible physical attributes and scrap characteristics. | UI |
| **Cross-Navigation to Map** | Direct **"Find Facilities for this Item"** button that auto-filters the facility directory for recyclers matching the scanned device. | UX |
| **Collapsible Raw JSON Drawer** | Developer inspection drawer with `<details>` collapsible tag showing raw API response payload. | Tooling |
| **"Clear & Re-analyze" Reset** | 1-click button to reset viewfinder, clear classification results, and return to standby state. | UX |

## 4. Smart Geolocation & "Near Me" Address Engine

| Feature | Description | Scope |
| :--- | :--- | :--- |
| **1-Click "Near Me" Location Button** | Navbar button triggering browser GPS location with active state styling. | Core |
| **Address-Based Reverse Geocoding** | Connects to **OpenStreetMap Nominatim** to resolve raw coordinates into real-world **City, District, and State**. | Core |
| **Haversine Distance Calculator** | Mathematical algorithm calculating real-world kilometer (`km`) distance between user and all 421 facilities. | Core |
| **Textual Address Match Fallback** | Fallback proximity weighting based on matching district and state names when GPS coordinates are unavailable. | Resilience |
| **Live User Location Badge** | Navbar pill displaying detected user locality (e.g. `Near Jaipur, Rajasthan` or `Near Bengaluru, Karnataka`). | UI |
| **Real-Time Distance Badges** | Renders exact distance badges (e.g. `14.2 km`) on every facility card and table row. | UI |
| **Auto-Sort by Closest First** | Automatically re-sorts the entire 421 facility dataset from closest to farthest when "Near Me" is activated. | UX |
| **Map Auto-Pan to User Region** | Smoothly flies the Leaflet map viewport to the user's detected coordinates. | UX |

## 11. Backend Architecture, APIs & Infrastructure

| Feature | Description | Scope |
| :--- | :--- | :--- |
| **Express 5 Backend Server (`server.js`)** | Lightweight, high-performance Node.js / Express backend hosting static files and API endpoints. | Backend |
| **Health Check Endpoint (`GET /api/health`)** | Returns server operational status, API key detection state, and active dataset endpoint. | API |
| **AI Vision Endpoint (`POST /api/analyze`)** | Accepts base64 image data URLs, forwards to NVIDIA OpenAI-compatible endpoint, parses and normalizes JSON. | API |
| **Multi-Key Environment Detection** | Automatically detects `NVIDIA_API_KEY`, `NVIDIA_NIM_KEY`, or `OPENAI_API_KEY` from `.env`. | Backend |
| **16MB Payload Handling** | Express body parser configured with `limit: "16mb"` to handle high-resolution image uploads seamlessly. | Backend |
| **CORS & Cross-Origin Support** | Configured `cors()` middleware supporting local file debugging and multi-port frontend setups. | Backend |
